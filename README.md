## Features:
- User Authentication: Secure login via AWS Cognito to authenticate users.
- API Configuration: Store Unipile API credentials locally for LinkedIn API access.
- Industry-based Prompts: Manage prompts for different industries in DynamoDB.
- LinkedIn User Search: Search LinkedIn users based on keywords, location, and other filters.
- Message Generation: Use Bedrock AI to generate personalized outreach messages.
- InMail Messaging: Send InMails directly to LinkedIn profiles using the Unipile API.

## Tech Stack:
- Frontend: Vite, React, TypeScript
- Backend: AWS Lambda, AWS AppSync, AWS DynamoDB, AWS Amplify
- Authentication: AWS Cognito
- API Integration: Unipile API
- AI Integration: Bedrock AI

## Setup Instruction
### Prerequisites:
- Ensure Node.js and npm are installed.
- Set up a Unipile account and retrieve the necessary API keys for LinkedIn integration.

## Installation:
1. Clone the repository:
```
git clone https://github.com/your-repo/linkedin-outreach-app.git
cd linkedin-outreach-app
```

2. Install dependencies:
```
npm install
```
3. Start the development server:
```
npm run dev
```
The application will be available at http://localhost:3000.

## Usage:
- **Authentication:**
    - Users must log in via the AWS Cognito login form to access the app.

- **API Configuration:**
    - Navigate to the "API Config" page.
    - Input the necessary Unipile API credentials:
        - API Key: Generated by Unipile.
        - Account ID: Linked to your LinkedIn profile via Unipile.
        - API Type: Provided when registering with Unipile.
    - Save the credentials, which will be stored in local storage for use in LinkedIn searches.
- **Industries Page:**
    - View and manage industry-specific prompts in a table format.
    - The table includes:
        - Industry Name
        - Prompt
    - You can add, edit, or delete industry prompts to customize outreach messages.

## Next Steps:
- LinkedIn User Search: Once API credentials are saved, you can start searching for LinkedIn profiles based on keywords and location filters in the Home page.
- Message Generation: Use Bedrock AI to generate personalized messages tailored to specific industries or user types.
- InMail Messaging: Directly send InMails to LinkedIn users you find through the search feature.
